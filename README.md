# Prepnest Library

Teaching resources, organized for discovery and preparation.

**Status: private review.**

Prepnest Library brings curriculum browsing, resource discovery, past-question navigation and editorial preparation into a structured product for teachers.

## What I’m building

- A clear route from curriculum and topic to relevant resources.
- Useful context for reviewing and preparing teaching material.
- Editorial workflows that keep draft and reviewed content distinct.

The November 2026 hosted review build passed build and TypeScript checks. Public launch, academic acceptance and complete product verification remain ahead.
